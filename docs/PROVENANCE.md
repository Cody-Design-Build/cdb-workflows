# Provenance and migration

Current boundary: all eight latest JobTread modules were consolidated back into cdb-workflows from the briefly independent jobtread-skills source. Dropbox is now a selectable module in this same library. The historical extraction account below explains provenance, not current maintenance ownership.

The five existing JobTread modules, their references, installer safety behavior and offline tests were extracted from the current reviewed working source of Cody-Design-Build/cdb-workflows, preserving latest local procedure edits before retiring that source. Git history, private evidence, client configuration and credentials were not imported. Original CDB-authored text/code remains MIT; David Cody and Cody Design Build retain attribution.

Job management is newly authored coordination guidance using the operating skill's existing safety rules. Daily logs consolidates the existing daily-log procedure into its own maintained module; the old reference routes there. Scheduling retains its week-block calculator and tests. Estimating is an authored starting-point adaptation of the current CDB-OS `.agents/skills/cdb-estimating/SKILL.md`: inputs → resolved scope → approved estimating baseline → scope pricing → customer proposal allocations. Its scope steps were read in full. The legacy estimating loader was reviewed only for conflict recognition, not adopted: its private rates/examples, old two-document workflow, blanket percentages, machine paths and dependencies are deliberately absent. No claim of importing or reviewing every legacy estimating rule is made. The private source review and exact source revision remain outside this public repository.

The structural JobTread schema snapshots were already published as reusable reference material in cdb-workflows. Their inherited provenance and known limits are retained in [schema notes](../skills/jobtread/references/schema-notes.md); original capture date/version is unknown. They are not live records or exhaustive recursive documentation. Full upstream tool descriptions are not republished. Upstream JobTread materials and trademarks remain subject to their owners' terms; the repository MIT license does not relicense them. Live schema discovery remains required.

Dropbox filing policy stays in the optional public cdb-workflows package. Team Dropbox onboarding notes point to this public GitHub source; they are not a second maintained skill implementation. Existing hosted-client attachments are distributed copies of an identified revision and require manual refresh.
