# Company briefing — as-of / audience / run ID

## Needs your decision
- Exact decision, options/consequences, recommended choice, deadline, evidence and approval scope.

## Next moves
- Next actor / action / job or company workstream / promised deadline vs proposed reminder / blocker / reason for priority.

## Blocked/waiting
- Who owes what; last verified contact/source; next review date; due waiting work with no new mail.

## Material developments
- Concise changes across relevant jobs and company work; separate source claims, verified facts and human decisions.

## Actions and receipts
- Created/updated tasks: exact record IDs/links and verified changes.
- Every task closure: completion condition, evidence, exact record and outcome receipt.
- Reopened tasks: human correction, preserved history and receipt.
- Drafts: exact unsent draft/thread IDs and readback, never imply sent.
- Other authorized writes: intent/outcome IDs and destination readback.
- Failed/uncertain attempts: reconciliation result and next decision; never hide in updated totals.
- Daily aggregation: include all run closures/outcomes; exact known run IDs and incomplete aggregation gaps.

## Coverage, freshness and handoff
- Mode; authorized sources/accounts and time window/change marker; last fresh reads.
- Per source: discovered / screened / fully reviewed / pending / failed; page/total reconciliation.
- Backfill/baseline scope vs fresh urgent coverage; exclusions and missing systems.
- Memory retained/verified as-of; consolidation/page lag or unknown/failed refresh.
- Cached/as-of disclosures; derived report is not independent evidence.
- Unreviewed unit IDs / previous complete watermark / uncertain action IDs / next resume unit.
- Budget actually used when measurable; costs/tokens unknown otherwise.
